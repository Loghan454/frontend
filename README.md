# 🕹️ Retro Memory Arcade

Um jogo da memória clássico com temática arcade retrô, desenvolvido diretamente com tecnologias web puras (Vanilla JS, HTML5 e CSS3). O projeto foca na simplicidade, leveza e nostalgia dos fliperamas clássicos.

## 📁 Estrutura do Projeto

O projeto possui uma arquitetura limpa e leve (aprox. 13 KB descompactado), organizada nos seguintes arquivos:

```
retro-memory-arcade/
├── index.html   # Estrutura principal e interface do jogo
├── style.css    # Estilização retrô, animações e layout responsivo
└── jogo.js      # Lógica de embaralhamento, turnos, pontuação e estado do jogo
```

## ✨ Funcionalidades

* **Estética Arcade Retrô:** Visual inspirado nos jogos clássicos com efeitos de transição em CSS.
* **Mecânica Clássica:** Sistema de virar cartas, verificação de pares, contagem de movimentos e condição de vitória.
* **Zero Dependências:** Construído 100% com HTML, CSS e JavaScript puro, sem necessidade de frameworks ou bibliotecas externas.

## 🚀 Como Executar

Como o projeto não utiliza ferramentas de build ou servidores complexos, você pode rodá-lo facilmente:

1. **Clone este repositório** (ou extraia os arquivos do projeto) em uma pasta no seu computador:
   ```bash
   git clone https://github.com/seu-usuario/retro-memory-arcade.git
   ```

2. Navegue até o diretório do projeto:
   ```bash
   cd retro-memory-arcade
   ```

3. Dê um duplo clique no arquivo `index.html` para abri-lo diretamente no seu navegador padrão.

*(Opcional)* Caso utilize o VS Code, você pode rodar o projeto através da extensão **Live Server** clicando com o botão direito no `index.html` e selecionando *"Open with Live Server"*.

## 🛠️ Tecnologias Utilizadas

* **HTML5** — Marcação semântica da interface.
* **CSS3** — Estilização temática e animações de virada das cartas.
* **JavaScript (ES6+)** — Manipulação do DOM e regras de negócio do jogo.
